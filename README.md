# 🛍️ E-Commerce Website

## 📌 Project Overview

This is a modern and responsive E-Commerce web application built with **React.js**. It allows users to browse products, search items, view product details, add products to the cart, and enjoy a smooth shopping experience through a clean and user-friendly interface.

---

## 🌐 Live URL

👉 https://first-e-commerce-mocha.vercel.app

---

## ✨ Key Features

- 🔐 User Authentication (Email & Google Login)
- 🛒 Add products to the shopping cart
- ❤️ Wishlist functionality
- 🔍 Search and filter products
- 📦 View detailed product information
- 🗂️ Browse products by category
- 📱 Fully responsive design
- ⚡ Fast and smooth user experience
- 🔒 Protected routes for authenticated users
- 🎯 Toast notifications for user actions

---

## 🧰 Tech Stack

- **React.js**
- **React Router DOM**
- **Tailwind CSS**
- **DaisyUI**
- **Firebase Authentication**
- **Axios**

## 🚀 Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/umayer10-AI/first-E-Commerce.git
```

### 2. Navigate to the Project Folder

```bash
cd ecommerce-website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Create a `.env.local` File

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

### 5. Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
